About Résumé Intelligence

Résumé Intelligence is an AI-powered recruitment platform designed to streamline the hiring process by automatically analyzing resumes, evaluating candidate skills, and matching applicants with suitable job roles.

Key Features
  • Automated Resume Parsing: Extracts text from PDF, DOCX, and TXT resumes using advanced NLP techniques.
  • Skill Extraction: Identifies technical and soft skills from resume content using a comprehensive skill dictionary.
  • Role Classification: Uses machine learning to predict the most suitable job category for each candidate.
  • Job Matching: Computes similarity scores between resumes and job descriptions using TF-IDF and cosine similarity.
  • Ranked Shortlist: Provides recruiters with a ranked list of candidates based on match scores.
  • Detailed Candidate Insights: Offers breakdowns of matched skills, missing skills, and role-fit confidence.
Technology Stack
  • Backend: Python Flask with scikit-learn for machine learning
  • Frontend: HTML5, CSS3, vanilla JavaScript
  • NLP Libraries: spaCy, NLTK, sklearn.feature_extraction.text
  • ML Models: Random Forest Regressor for match score prediction
  • Styling: Custom CSS with Playfair Display and Source Sans Pro typography
How It Works
  1. Recruiter inputs a job description
  2. Resumes are uploaded (PDF/DOCX/TXT) or pasted manually
  3. Each resume is processed to extract text and features
  4. The AI model predicts role category and computes match score against the job description
  5. Candidates are ranked by their match score
  6. Recruiter can view detailed insights for each candidate
